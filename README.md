# Weather App

A responsive weather application built using React and Vite that provides real-time weather information and forecasts.

## Features

- Real-time weather data
- Search weather by city
- Modern and responsive UI

## Tech Stack

- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Node.js, Express
